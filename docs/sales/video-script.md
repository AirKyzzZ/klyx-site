# Script vidéo Loom (60-90 s)

Format : Loom, caméra en bulle dans un coin, écran partagé. Une prise, ton parlé, pas de lecture mot à mot. Environ 80 secondes (210 mots dits).
Usage : lien envoyé après un premier échange (réponse à un DM, demande de devis), ou en tête de la page contact. Une version générique, et le début se personnalise en 10 secondes pour un prospect précis.
